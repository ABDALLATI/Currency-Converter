# Currency Converter App 💱

A modern, fast, and responsive web application that converts currencies in real-time using live exchange rates.

## ✨ Features

- 🔄 **Real-Time Exchange Rates:** Fetches up-to-date conversion data using a live REST API.
- 📱 **Fully Responsive:** Beautiful and functional design across all devices (Mobile, Tablet, Desktop).
- 🔀 **Instant Swap:** Quickly switch between source and target currencies with a single click.
- ⚡ **Fast & Lightweight:** Built using clean semantic HTML and modular JavaScript.
- 🛡️ **Error Handling:** Clear notifications for network failures or invalid user inputs.

## 🛠️ Built With

- **HTML5:** Semantic structural layout.
- **CSS3:** Modern styling, Flexbox/Grid, and responsive layout units.
- **JavaScript (ES6+):** Dynamic DOM manipulation and asynchronous data fetching (`async/await`).
- **Fetch API:** Integration with external currency exchange endpoints.
